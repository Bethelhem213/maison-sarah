# Maison Sarah Website

Welcome to the Maison Sarah website! This project showcases a bakery that specializes in handmade bread and pastries.

## Project Structure

- `index.html`: The homepage featuring a welcome message, bakery description, and location details.
- `menu.html`: A page that lists the menu offerings of Maison Sarah, including a variety of baked goods.
- `order.html`: A page that allows customers to place orders for their favorite items.
- `images/`: A directory containing images used throughout the website.

## Setup Instructions

1. Clone the repository to your local machine.
2. Open the project folder in your preferred web browser.
3. Navigate through the website using the provided links in the header.

## Usage

- Visit the homepage to learn more about Maison Sarah.
- Check the menu to see available items.
- Use the order page to place your orders directly.
